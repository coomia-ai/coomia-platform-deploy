# 2026.10.04-trial.22 共享试用镜像目录

[English](README.en.md) | 简体中文

本目录是共享试用部署的权威镜像目录。四个一方镜像已通过保护构建、双阶段安全门禁、SBOM、
GHCR Public 发布和匿名 RepoDigest 读取验证；基础设施摘要沿用已经验证的 `trial.7` 目录。

Compose 配置初始化和 Kubernetes 参考安装器会从本目录读取默认值。普通试用用户不需要从官网复制
镜像摘要。只有厂商明确交付客户专有镜像时，才应通过环境变量覆盖这些默认值。

该目录固定镜像和制品摘要，不改变根目录 `RELEASE_STATUS=PREPARED`；完整 K8s 自助安装器、
全产品回归和人工批准完成前仍不得宣称正式可交付。
