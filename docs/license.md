# License 操作

[English](license.en.md) | 简体中文

平台在 `LICENSE_ENFORCEMENT=true` 时执行授权校验。授权文件、在线激活凭据和授权状态均属于敏感资产。

## 在线模式

设置 `LICENSE_MODE=online` 和交付方提供的 `LICENSE_SERVER_URL`。客户网络必须允许 API 容器访问该服务，并正确配置 DNS、系统时间和 CA 信任链。

激活后在授权管理页面确认产品、有效期、功能范围和实例标识。任何授权错误都应先保留 API 日志和当前时间，再联系交付方。

## 离线模式

1. 将交付方公钥保存到客户受控目录，权限设为只读。
2. 在 `compose/.env` 中设置 `LICENSE_MODE=offline` 和公钥绝对路径。
3. 启动平台后，从授权管理页面导入签名的 JWT License 文件。

公钥用于验签，不包含签发能力。License 私钥不得出现在客户部署包、镜像或运行环境中。

## 更新与到期

在到期前取得新 License，并通过授权管理页面替换。替换后验证页面状态和受控功能。不要修改 JWT 内容、文件名扩展规则或容器内授权状态文件。

到期后的具体行为由该版本授权策略决定，可能包括提醒、限制新任务或拒绝受控功能。License 到期不应触发数据卷删除。

## 备份与审计

授权状态保存在 `license-state` 卷。备份时应与平台数据库保持同一恢复点。审计记录至少包含版本、实例标识、License 指纹、激活时间、到期时间和操作者，不应记录完整 License 内容。

## 常见错误

- “已使用”：该 License 已绑定其他实例或不允许重复激活。
- “签名无效”：公钥、文件内容或签发环境不匹配。
- “未生效”：检查容器时间、License 模式、公钥挂载和 API 日志。
- “服务不可用”：先确认 API 健康；503 通常不是单纯由授权到期导致。
